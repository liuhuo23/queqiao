# 管理台使用

## 登录

通过 SSH 隧道访问：

```bash
ssh -L 7610:127.0.0.1:7610 root@YOUR_SERVER_IP
# 浏览器打开 http://127.0.0.1:7610
```

用户名默认 `admin`，初始密码见服务端 `/var/lib/queqiao/initial-admin.txt`。

## 页面

| 页面 | 能做什么 |
|------|----------|
| 概览 | 在线设备、规则数、连接数、流量、待审批提醒 |
| 设备 | 批准/拒绝新设备；改名、备注、封禁/解封、重绑定机器、删除 |
| 映射 | 新建/编辑/启停/删除 TCP 与 HTTP 映射；端口预检 |
| 日志 | 审计日志（管理员操作）与 Agent 事件 |
| 设置 | 公网主机、端口段、HTTP 监听、自动批准、限制、改密码 |

## 设备审批

1. 客户端首次连接后出现在「设备」页，状态为 **待审批**；
2. 核对终端打印的密钥码（形如 `QIAO-XXXX-XXXX-XXXX`）与网页一致；
3. 点「批准」→ 设备变为 active，客户端自动连上；
4. 也可以「拒绝」（删除记录），或在已批准设备上「封禁」。

**机器指纹**：首次连接会绑定机器码；换机/重装系统后会提示指纹冲突，点「重绑定机器」后设备回到待审批，重新批准即可。

**删除**：删除设备会同时吊销该公钥（私钥无法再重新登记），并删除它的全部映射。

## 映射

- **TCP**：公网端口 → 本机端口，例如 `127.0.0.1:8080 → 39001`；适合 HTTP、SSH、数据库等。
- **HTTP**：按域名路由，需要先在设置里配置 `http_addr`（如 `:39080`），再把域名解析到服务器。

新建时可直接点「检测端口」检查公网端口是否可用。修改后立即下发，客户端不需要重启。

## 自动刷新

默认 4 秒轮询（日志 8 秒），但**只有数据变化才重绘**：心跳、流量、运行时长原地更新，滚动位置保持，输入/弹窗/选中文本时自动暂停。

- 顶栏「自动刷新」可随时暂停/恢复（状态会记住）；
- 「刷新」立即手动刷新当前页；
- 页面切到后台时暂停轮询。

## 设置说明

| 设置 | 说明 |
|------|------|
| 公网主机 | 网页展示用，如 `YOUR_SERVER_IP` |
| 端口段 | 允许分配的映射端口范围 |
| HTTP 监听 | HTTP 域名映射监听地址（空=关闭） |
| 自动批准 | 新设备免审批（不建议公网环境开启） |
| 最大设备数 / 每设备映射上限 | 资源限制 |
| 会话有效期 | 管理台登录会话时长 |
| 流量统计 | 关闭后不统计隧道流量（连接数仍统计） |
