# 鹊桥 Queqiao

> 免配置内网穿透：**服务端集中配置，客户端零配置，网页即管理入口**。

鹊桥把本机或内网里的服务（HTTP、SSH、数据库、开发服务器……）通过一台有公网 IP 的服务器暴露出去。
客户端只需安装一次并连接服务端；之后所有端口映射、审批、封禁都在服务端网页上完成，改完秒级生效。

## 它和 frp 有什么不同

| | frp | 鹊桥 |
|---|---|---|
| 客户端配置 | 每台机器写 `frpc.toml`，改映射要改文件重启 | 无配置文件，映射全在服务端网页 |
| 身份 | 预共享 token | 客户端生成 Ed25519 密钥 + 机器指纹绑定 + 管理员审批 |
| 配置事实源 | 配置文件 | 服务端 state + 网页管理台 |
| 适合 | 通用/团队/复杂拓扑 | 个人多设备、给非技术用户装一次就不用管 |

## 30 秒流程

```text
1. 服务器安装 queqiaod，打开网页管理台
2. 本机运行：queqiao -s 你的服务器:7600
3. 网页「设备」批准这台机器
4. 网页「映射」添加：127.0.0.1:8080 -> 公网 39001
5. 访问 http://你的服务器:39001
```
